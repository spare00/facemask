# facemask

맥 화면 위에 떠 있는 선 얼굴이다. 눈, 눈썹, 코, 입만 그려지고, 로컬 Ollama 모델과 대화한다.

macOS 14 이상이 필요하다. 모델은 이 컴퓨터의 Ollama(`http://127.0.0.1:11434`)를 쓴다.

## 켜기

저장소 폴더에서 실행한다.

```bash
swift run
```

도크 아이콘은 없다. 메뉴 막대에 작은 얼굴이 생긴다.

## 끄기

메뉴 막대의 얼굴 아이콘을 누르고 **종료**를 고른다.

## 사용

얼굴 아래 칸에 메시지를 입력하고 Return을 누른다.

- 답을 기다리는 동안은 생각 중이고, 눈썹은 궁금한 표정이다.
- 답이 오면 첫 줄의 감정으로 눈썹이 바뀌고, 나머지 문장을 읽어 준다. 읽는 동안은 말하는 중이다.
- 읽기가 끝나면 대기 상태로 돌아간다.

얼굴 부분을 드래그하면 창이 이동한다. 대화 중이 아닐 때 얼굴을 클릭하면 대기, 생각 중, 말하는 중이 순서대로 바뀐다.

메뉴의 **감정**에서 표정을 고정할 수 있다. **자동**을 고르면 다시 대화 상태를 따른다.

| 감정 | 모습 |
| --- | --- |
| calm | 평온 |
| curious | 궁금 |
| surprised | 놀람 |
| skeptical | 의심. 한쪽 눈썹이 올라간다 |
| concerned | 걱정. 눈썹 안쪽이 모인다 |

모델은 답의 첫 줄에 위 단어 중 하나만 쓰고, 다음 줄부터 할 말을 쓴다.

## 모델

`FACEMASK_MODEL`이 있으면 그 모델을 쓴다. 없으면 설치된 모델 중에서 `qwen3:latest`, `qwen2.5:14b`, `qwen2.5:14b-ctx` 순서로 고르고, 그것도 없으면 목록의 첫 모델을 쓴다.

```bash
FACEMASK_MODEL=qwen2.5:14b swift run
```

Ollama가 꺼져 있거나 모델이 없으면 얼굴 아래에 짧은 안내가 나온다. 연결된 모델 이름은 메뉴 막대에 표시된다.
